# Planning Update 03: approved architecture baseline

Status: **approved planning baseline** (35 of 35 decisions), 2026-11-21. Approval of the direction is not approval to build every feature; each phase is authorised separately.

The full decision text is Jason's "Architecture & Feature Planning Update 03". The codebase alignment report and phase plan are in the Claude Doc "PickWorks Studio: Codebase-to-Architecture Alignment Report".

## What changed from earlier documents

- **Hybrid Mastery is approved** (Decision 01). It supersedes the "recommended, not locked" note in [planning-update-02.md](planning-update-02.md). The v1 note-mastery rule stays the baseline.
- Six shared engines: Learning, Music Theory and Instrument, Audio Services, Content System, Student Data and Reporting, Connectivity Policy.
- Five phases: 1 Core Foundations, 2 Essential Learning Experience, 3 Expanded Learning and Creative Tools, 4 Advanced Learning Ecosystem, 5 Platform and Optional Service Expansion. (Scheduling note, 2026-11-22: phases 3 and 4 are now planned as expansion stages X0 to X7 in [master-roadmap.md](master-roadmap.md); phase 5 is the Android release and any optional online services.)

## Rules that stay in force

Show Answer hidden in assessments; revealed answers never count; standalone practice never confers curriculum mastery; Tuner above Progress; Print Studio 1/2/4/6 per page; left-handed display; approved branding; local files authoritative; no mandatory account, internet or subscription.

## Phase 1 scope (approved to build 2026-11-21)

App shell and navigation, local student profiles and persistence, versioned schemas, crash-safe storage, curriculum and skill data structures, fretboard engine, native chord-diagram generator, tuner, metronome, essential accessibility and left-handed layouts, connectivity policy, basic local backup, plus the Update 04 account system.
